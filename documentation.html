Command Documentation

Every command works as a slash command and as a prefix command. In the examples below, replace <prefix> with your server's prefix. Parameters in [square brackets] are optional.

General

/ping Check that DataPoint is online Everyone

Shows the bot's latency.

Usage

/ping
<prefix>ping

Parameters

None.

/prefix Show this server's command prefix Everyone

Shows the server's prefix.

Usage

/prefix
<prefix>prefix

Parameters

None.

Server setup

/server-settings Configure DataPoint for your server Server admin

Opens the server settings menu.

Usage

/server-settings
<prefix>server-settings

Parameters

None.

Pages

  1. Server admin roles: roles with full permissions on every table.
  2. Member log channel: where member commands are logged.
  3. Manager log channel: where manager commands are logged.
  4. Admin log channel: where admin commands are logged.
  5. Failed attempts: log commands used without permission.
  6. Backups: where daily backups are sent.
/set-prefix Change the command prefix Server admin

Changes the server's prefix.

Usage

/set-prefix prefix:<prefix> [include_space:True]
<prefix>set-prefix <new prefix> [true]

Parameters

NameRequiredDescription
prefixYesThe new prefix (max 3 characters).
include_spaceNoAdds a space after the prefix.

Tables

/create-table Create a new table Server admin

Creates a new table.

Usage

/create-table name:<table name>
<prefix>create-table <table name>

Parameters

NameRequiredDescription
nameYesThe table's name (max 50 characters).
/table-settings Configure a table Server admin

Opens the settings menu for a table.

Usage

/table-settings table_name:<table name>
<prefix>table-settings <table name>

Parameters

NameRequiredDescription
table_nameYesThe table to configure.

Pages

  1. Rename table: change the table's name.
  2. Manage columns: add or remove columns.
  3. Member roles: can request rows and view their own.
  4. Manager roles: can review requests and view the whole table.
  5. Admin roles: can add and remove any row.
  6. Request channel: where requests are sent.
  7. Request pings: ping managers on new requests.
/delete-table Delete a table and all its rows Server admin

Permanently deletes a table.

Usage

/delete-table name:<table name>
<prefix>delete-table <table name>

Parameters

NameRequiredDescription
nameYesThe table to delete.

Adding rows

/add-row-by-request Request to add or update your row Member

Requests to add or update your row. A manager must approve it.

Usage

/add-row-by-request name:<table name>
<prefix>add-row-by-request <table name> <value 1> <value 2> ...

Parameters

NameRequiredDescription
nameYesThe table to add your row to.
valuesPrefix onlyOne value per column, in order.
/add-row-by-user Add or update anyone's row directly Table admin

Adds or updates a user's row without approval.

Usage

/add-row-by-user name:<table name> user:<@user>
<prefix>add-row-by-user <table name> <@user> <value 1> <value 2> ...

Parameters

NameRequiredDescription
nameYesThe table to add the row to.
userYesThe user whose row to add or update.
valuesPrefix onlyOne value per column, in order.
